## 2024-05-24 - PySpark Aggregation Optimization
**Learning:** Performing multiple scalar aggregations (like `.count()` and `.filter(...).count()`) on the same DataFrame triggers separate Spark jobs and can lead to redundant full-table scans, severely impacting performance.
**Action:** Combine these metrics into a single `.select()` operation using conditional aggregations like `F.sum(F.when(..., 1).otherwise(0))` and `F.count('*')`, followed by a single `.collect()[0]` to extract the scalar values efficiently in one pass. Ensure you use an `or 0` fallback when extracting the dictionary values, as `F.sum()` on an empty DataFrame returns `None`.
