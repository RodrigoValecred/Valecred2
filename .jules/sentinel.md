## 2025-02-18 - [Insecure External Script Execution in Notebooks]
**Vulnerability:** Notebooks were downloading external Python scripts (`extract_dump.py`) and running them without verifying their integrity, relying solely on HTTPS and GitHub commit hashes (which are good but insufficient if the source repo is compromised or the commit is spoofed/mutable if not fully pinned). Critical files like `requirements.txt` were missing from the download list, leading to potential execution of untrusted or stale local files during `pip install`.
**Learning:** External code dependencies in Notebooks must be treated as untrusted input. Relying on "helper files" lists that are manually maintained can lead to missing dependencies (`requirements.txt`) and security gaps.
**Prevention:** Always implement cryptographic hash verification (SHA256) for any external code downloaded and executed within the environment. Explicitly list and pin all dependencies, including transitive ones like `requirements.txt`.
